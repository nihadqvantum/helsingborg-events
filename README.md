# Helsingborg + nearby events

PWA for concerts, culture, sports, and city events around Helsingborg.

- Map with family (teal) and night-out (coral) pins
- Photo list; tap a card for the official event page
- Installable; notify toggle for new events
- Daily backend search via Vercel cron (`/api/cron` at 06:00 UTC)

```bash
npm install
npm run dev
```
